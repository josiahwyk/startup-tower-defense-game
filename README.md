# Startup Tower Defense

A browser-based roguelite tower defense game where you build a startup team to fend off threats. Choose from 13 employee types and 8 office perks, and survive infinite, escalating waves.

The whole game is one self-contained HTML file: open `startup-defense.html` in a browser to play. No install or build step.
